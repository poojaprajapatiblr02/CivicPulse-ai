# Synthetic Data

**SYNTHETIC / DEMO DATA. Not real government statistics or real citizen reports.**

Generated by `../scripts/generate_data.py` with fixed seed 42. CSVs are UTF-8
and include a `data_source` label on every row. All names and coordinates are
fictional fixtures; coordinates are reused from demographics, never inferred by AI.

| File | Rows | Grain |
| --- | ---: | --- |
| citizen_requests.csv | 500 | One synthetic request |
| demographics.csv | 50 | One location; 10 fictional districts |
| infrastructure.csv | 250 | One location and category |
| government_investments.csv | 250 | One location and category for 2026-27 |

Languages: English, Hindi, Kannada. Categories: Healthcare, Education, Roads,
Water, Electricity. Requests use fixed templates, not Gemini or machine translation.
The `problem` column is a template-based English normalization, not AI analysis.
Timestamps are timezone-aware UTC dates in July-August 2026, not the current clock.

## Synthetic Relationships

Demand allocation weight = population * (0.2 + 1 - service coverage).
Largest-remainder allocation creates exactly 500 requests. Funding ratios rise
with service coverage, so lower investment ratios accompany larger capacity deficits.
These are deliberate simulation assumptions, not empirical causal findings.
Urgency combines service shortfall and a fictional vulnerability index on 0-1.

Infrastructure capacities use category-specific units: people served, student seats,
road kilometres, or household connections. Distance is populated only for health
and education; service hours only for water and electricity; condition only for roads.
Blank non-applicable CSV fields map to nullable BigQuery columns.

Investment and estimated need are INR. Estimated need is an illustrative full
service-capacity cost, not a government-approved estimate or spending proposal.
No hotspot, infrastructure-gap score, priority score, or recommendation is computed.
